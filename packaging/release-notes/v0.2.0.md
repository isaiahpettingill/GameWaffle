## Studio and scripts

- Work with the room preview and project sidebar on the left and Blockly or WaffleScript on the right. Pick entity and room scripts directly, including from the sidebar. The Room tab is dedicated to room editing.
- Build behavior with `On tick`, held and just-pressed inputs, typed values, constants, trig, custom routines with draggable parameters, `else if` chains, and events that expose their sender. Detached blocks stay in the workspace as inactive code.
- Paint past room edges to grow the room, preview the extended grid, and pan or zoom with a mouse or touch gestures. Studio remembers the view. Import background images in the room inspector and set camera targets, zoom, and shaders from room scripts.
- Build game objects from collision shapes, entity fields, events, impulses, and damage. Sprites support generated colliders, per-frame custom shapes, transforms, shadows, and optional health bars. HUD scripts can position text, select bitfonts, and show a minimap.
- Initialize games, rooms, entities, and tile variants from scripts. Room defaults generate an editable On init stack for each new room. Tiles expose contact events, timers, playback, body controls, and friction.
- Declare typed, owned objects, inventories, player properties, and numeric arrays in the Game script. Assign player control and react to controller connections in scripts.
- Draw shapes in room or HUD coordinates. Add MIDI with SF2 SoundFonts alongside WAV, Ogg Vorbis, and Opus, and select them in room audio scripts.
- Import bitfonts from YAFF, Aseprite, or PNG. Use a single export dialog for platforms and languages. Cover art is embedded in the exported cartridge.

## Runtime and players

- Hot real arithmetic can run through Cranelift on desktop and generated WebAssembly on the web. The interpreter also has faster dispatch for common variable updates.
- Rapier2D replaces Box2D. Web and desktop builds use SIMD, and libretro save states capture physics and audio state for deterministic replay.
- The Android player remembers your cartridge folder and shows game covers. The touch controller has a left D-pad, centered Start, and three face buttons on the right. Portrait controls sit below gameplay.
- Linux and Windows players can enable touch controls with F3 or `--touch`. Direct touchscreens are detected as they are used. macOS can build from source with Cargo.
- Standalone players open to a cartridge picker or library. Studio playtests and game exports launch their selected cartridge.

Installers and players are attached below, along with Android Studio, the offline web player, and libretro cores for Linux, Windows, and Android. Re-export from Studio to use the new runtime features in existing projects.
